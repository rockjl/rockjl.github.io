一、Rust 基础类型

Rust 是 静态类型语言（编译时确定类型），基础类型分为「标量类型」（单个值）和「复合类型」（多个值组合），类型标注可省略（编译器自动推导），但复杂场景必须显式标注。

1. 标量类型（4 种）

（1）整数类型

  • 核心概念：有符号（i 开头）/ 无符号（u 开头），后缀表示位数（8/16/32/64/128/arch）
  • 常用类型：i32（默认有符号整数）、u32（默认无符号整数）、isize/usize（与系统架构一致，用于索引）
  • 示例：
fn main() {
    let a: i32 = -42;       // 有符号32位整数
    let b: u32 = 100;       // 无符号32位整数
    let c = 5;              // 自动推导为 i32
    let d: usize = 10;      // 适合作为数组索引（64位系统是u64，32位是u32）
    
    println!("a={}, b={}, c={}, d={}", a, b, c, d);
}

（2）浮点数类型

  • 核心概念：带小数的数值，仅 f32（单精度）和 f64（双精度，默认）
  • 示例：
fn main() {
    let x: f32 = 3.14;      // 单精度浮点数
    let y = 2.718;          // 自动推导为 f64（精度更高，推荐使用）
    let sum = x + y;
    
    println!("sum={}", sum); // 输出 sum=5.858
}

（3）布尔类型（bool）

  • 核心概念：仅两个值 true/false，占 1 字节，不可隐式转换为整数（区别于 C/Python）
  • 示例：
fn main() {
    let is_ok: bool = true;
    let has_error = false;
    
    // 错误：bool 不能转成整数 → error[E0308]: mismatched types
    // let num = is_ok as i32;
    
    println!("{}", is_ok && has_error); // 逻辑与 → false
    println!("{}", is_ok || has_error); // 逻辑或 → true
}

（4）字符类型（char）

  • 核心概念：Unicode 字符（支持中文、表情），用单引号包裹，占 4 字节
  • 示例：
fn main() {
    let ch1: char = 'A';    // 英文大写字母
    let ch2 = '中';         // 中文汉字（支持Unicode）
    let ch3 = '😀';         // 表情符号（也是Unicode字符）
    
    println!("ch1={}, ch2={}, ch3={}", ch1, ch2, ch3);
}

2. 复合类型（基础 2 种）

（1）元组（Tuple）

  • 核心概念：固定长度、可包含不同类型值的集合，长度编译时确定，不可修改
  • 语法：(值1, 值2, ...)，访问用「点号 + 索引」，或通过「解构赋值」提取
  • 示例：
fn main() {
    // 定义元组（类型标注可省略）
    let person: (&str, i32, bool) = ("Alice", 25, true);
    
    // 方式1：点号+索引访问（索引从0开始）
    println!("姓名：{}", person.0); // 输出 姓名：Alice
    println!("年龄：{}", person.1); // 输出 年龄：25
    
    // 方式2：解构赋值（推荐，更简洁）
    let (name, age, is_student) = person;
    println!("{}，{}岁，是否学生：{}", name, age, is_student);
    
    // 空元组（单元值）：表示「无返回值」，函数默认返回 ()
    let unit = ();
    println!("空元组：{:?}", unit); // 输出 空元组：()
}

（2）数组（Array）

  • 核心概念：固定长度、相同类型值的集合，存储在栈上（区别于动态集合 Vec），长度不可修改
  • 语法：[类型; 长度] 或 [值1, 值2, ...]，访问用「方括号 + 索引」
  • 示例：
fn main() {
    // 方式1：显式长度+重复值（创建5个0的i32数组）
    let arr1: [i32; 5] = [0; 5];
    println!("arr1: {:?}", arr1); // 输出 arr1: [0, 0, 0, 0, 0]
    
    // 方式2：直接罗列值（自动推导类型和长度）
    let arr2 = [10, 20, 30, 40];
    println!("arr2[2] = {}", arr2[2]); // 输出 arr2[2] = 30
    
    // 数组长度：用 std::mem::size_of_val 或 .len()
    println!("arr2长度：{}", arr2.len()); // 输出 4
    println!("arr2占用字节：{}", std::mem::size_of_val(&arr2)); // 4*4=16字节（i32占4字节）
    
    // 错误：数组长度固定，不能新增元素 → error[E0596]: cannot borrow `arr2` as mutable
    // arr2.push(50);
}

关键注意事项

  • 整数溢出：调试模式（默认）下溢出会 panic，发布模式（--release）下会环绕（不推荐依赖），建议用 checked_add 等安全方法
  • 字符与字符串：char 是单个 Unicode 字符，&str/String 是字符序列（后续详细讲）
  • 数组 vs 元组：数组是「同类型 + 固定长度」，元组是「异类型 + 固定长度」

二、Rust 流程控制

Rust 流程控制分为「条件判断」和「循环」，语法简洁且安全（无空指针风险）。

1. 条件判断（if-else）

  • 核心规则：条件表达式必须是 bool 类型（不可隐式转换，区别于 C/Python）
  • 语法：支持多分支 if-else if-else，且 if 可作为表达式返回值（类似三元运算符）
  • 示例：
fn main() {
    let score = 85;
    
    // 基础多分支
    if score >= 90 {
        println!("优秀");
    } else if score >= 80 {
        println!("良好");
    } else if score >= 60 {
        println!("及格");
    } else {
        println!("不及格");
    }
    
    // if 作为表达式（返回值）：适合简单条件赋值
    let grade = if score >= 80 { "A" } else if score >= 60 { "B" } else { "C" };
    println!("等级：{}", grade); // 输出 等级：A
}

2. 循环（3 种）

（1）loop：无限循环（手动终止）

  • 核心用途：不确定循环次数时使用，用 break 终止（可带返回值）
  • 示例：
fn main() {
    let mut count = 0;
    
    // 无限循环，break 返回值
    let result = loop {
        count += 1;
        if count == 5 {
            break count * 2; // 终止循环并返回 10
        }
    };
    
    println!("result: {}", result); // 输出 result: 10
}

（2）while：条件循环

  • 核心用途：确定循环条件时使用，条件为 true 时执行
  • 示例：
fn main() {
    let mut num = 3;
    
    while num > 0 {
        println!("num: {}", num); // 输出 3、2、1
        num -= 1;
    }
}

（3）for：迭代循环（最常用）

  • 核心用途：遍历迭代器（数组、切片、Vec、Range 等），安全且高效（无越界风险）
  • 语法：for 变量 in 迭代器，常用 0..n（左闭右开区间）生成迭代器
  • 示例：
fn main() {
    // 遍历 Range（0..5 → 0,1,2,3,4）
    for i in 0..5 {
        println!("i: {}", i);
    }
    
    // 遍历数组（推荐：无需索引，避免越界）
    let arr = [10, 20, 30];
    for val in arr {
        println!("值：{}", val); // 输出 10、20、30
    }
    
    // 遍历数组并获取索引：用 .iter().enumerate()
    for (index, val) in arr.iter().enumerate() {
        println!("索引{}：{}", index, val); // 输出 索引0：10、索引1：20...
    }
    
    // 反向遍历：用 .rev()
    for i in (0..5).rev() {
        println!("反向i: {}", i); // 输出 4、3、2、1、0
    }
}

关键注意事项

  • if 条件必须是 bool：不能写 if 1 { ... }（C 语言允许），需显式判断 if 1 != 0 { ... }
  • for 循环优先于 while：遍历集合时，for 无需手动管理索引，避免越界（Rust 不允许数组越界访问，编译时检查）
  • loop 的返回值：只有 loop 支持 break 带返回值，while/for 不支持

三、Rust 函数

函数是 Rust 代码组织的核心，语法严谨，支持参数、返回值、递归、嵌套定义。

1. 核心概念

  • 定义关键字：fn
  • 语法结构：fn 函数名(参数列表) -> 返回值类型 { 函数体 }
  • 关键规则：
    • 参数必须显式标注类型（编译器不推导参数类型）
    • 返回值有两种方式：① 函数体最后一行表达式（无分号）；② return 语句（适合提前返回）
    • 无返回值时，返回类型可省略（默认返回空元组 ()）

2. 代码示例

// 1. 无参数、无返回值函数
fn greet() {
    println!("Hello, Rust!");
}

// 2. 有参数、有返回值函数（返回表达式结果）
fn add(a: i32, b: i32) -> i32 {
    a + b // 无分号 → 表达式作为返回值（推荐）
}

// 3. 多返回值函数（用元组包装）
fn split_num(num: i32) -> (i32, i32) {
    let even = num % 2 == 0;
    if even {
        return (num / 2, 0); // 提前返回（带分号）
    }
    (num / 2, 1) // 最后一行表达式返回
}

// 4. 嵌套函数（内部函数，仅外层可见）
fn outer() {
    fn inner() {
        println!("我是嵌套函数");
    }
    inner(); // 只能在 outer 内部调用
}

// 5. 递归函数（计算阶乘）
fn factorial(n: u32) -> u32 {
    if n == 0 {
        1 // 基线条件
    } else {
        n * factorial(n - 1) // 递归调用
    }
}

fn main() {
    greet(); // 输出 Hello, Rust!
    
    let sum = add(3, 5);
    println!("3+5={}", sum); // 输出 8
    
    let (quotient, remainder) = split_num(7);
    println!("7拆分：商={}, 余数={}", quotient, remainder); // 输出 3,1
    
    outer(); // 输出 我是嵌套函数
    
    let fact = factorial(5);
    println!("5的阶乘：{}", fact); // 输出 120
}

关键注意事项

  • 参数类型必须标注：fn add(a, b) -> i32 { ... } 会编译错误，需写 a: i32, b: i32
  • 返回值表达式无分号：如果写 a + b;，函数会返回 ()（空元组），而非 i32
  • 嵌套函数作用域：内部函数只能在外部函数体内调用，不能在外部访问
  • 递归必须标注返回类型：编译器无法推导递归函数的返回类型，必须显式标注

四、Rust 所有权（Ownership）

所有权是 Rust 最核心的特性，用于管理内存（无需 GC 和手动释放），核心目标是「避免空指针、悬垂引用、数据竞争」。

1. 核心规则（必须牢记）

  1. 每个值在 Rust 中都有一个「所有者」（变量）
  2. 同一时间只能有一个所有者（避免数据竞争）
  3. 当所有者离开作用域（} 结束），值会被自动销毁（内存释放）

2. 核心概念解析

（1）作用域与自动销毁

fn main() {
    {
        let s = String::from("hello"); // s 进入作用域（所有者是 s）
        println!("{}", s); // 可用
    }
    // s 离开作用域 → 自动调用 drop 函数释放内存（无需手动 free）
    // println!("{}", s); // 错误：s 已被销毁，无法访问
}

（2）移动（Move）：所有权转移

  • 核心：当把一个非 Copy 类型（如 String、Vec）赋值给另一个变量时，原变量会失去所有权（变为无效），避免双重释放
  • 示例：
fn main() {
    let s1 = String::from("hello");
    let s2 = s1; // 所有权从 s1 转移到 s2（s1 失效）
    
    println!("{}", s2); // 正确：s2 是所有者
    // println!("{}", s1); // 错误：s1 已失去所有权（value borrowed here after move）
}

（3）克隆（Clone）：深拷贝（手动复制数据）

  • 核心：如果需要保留原变量的所有权，且复制数据（而非转移所有权），用 clone() 方法（深拷贝，堆上数据复制）
  • 示例：
fn main() {
    let s1 = String::from("hello");
    let s2 = s1.clone(); // 深拷贝：s1 和 s2 各自拥有独立数据
    
    println!("s1: {}, s2: {}", s1, s2); // 正确：两者都有效
}

（4）Copy 特性：浅拷贝（无需转移所有权）

  • 核心：标量类型（i32、bool、char 等）和元组（仅包含 Copy 类型）默认实现 Copy 特性，赋值时会「浅拷贝」，原变量仍有效
  • 示例：
fn main() {
    let x: i32 = 5;
    let y = x; // i32 是 Copy 类型，浅拷贝（栈上数据复制）
    
    println!("x: {}, y: {}", x, y); // 正确：x 和 y 都有效
    
    // 元组（包含 Copy 类型）也支持 Copy
    let t1 = (10, true);
    let t2 = t1;
    println!("t1: {:?}, t2: {:?}", t1, t2); // 正确
}

3. 所有权与函数传参 / 返回值

  • 函数传参：非 Copy 类型会转移所有权到函数参数，函数执行完后参数离开作用域，值被销毁（除非返回）
  • 示例：
fn take_ownership(s: String) {
    println!("函数内：{}", s);
} // s 离开作用域 → 数据被销毁

fn return_ownership(s: String) -> String {
    s // 返回 s，所有权转移给调用者
}

fn main() {
    let s1 = String::from("hello");
    take_ownership(s1); // s1 所有权转移到函数 → s1 失效
    // println!("{}", s1); // 错误
    
    let s2 = String::from("world");
    let s3 = return_ownership(s2); // s2 所有权转移到函数，再转移到 s3
    println!("s3: {}", s3); // 正确
}

关键注意事项

  • 区分 Move/Copy/Clone：
    • Move：非 Copy 类型赋值 / 传参，原变量失效（默认行为）
    • Copy：标量类型，浅拷贝，原变量有效（自动实现）
    • Clone：手动深拷贝，原变量有效（需显式调用 clone()）
  • 堆 vs 栈：Copy 类型通常存储在栈上（快速复制），非 Copy 类型（String、Vec）存储在堆上（深拷贝成本高，默认 Move）
  • 避免不必要的 Clone：优先用引用（后续讲）代替 Clone，提升性能

五、Rust 引用（Reference）

引用是「指向值的指针」，但不拥有值的所有权，核心用途是「在不转移所有权的情况下访问值」，避免频繁 Clone。

1. 核心概念

  • 语法：&T（不可变引用）、&mut T（可变引用）
  • 关键规则（ Rust 安全核心）：
    1. 同一时间，一个值要么有多个不可变引用（&T），要么有一个可变引用（&mut T）（避免数据竞争）
    2. 引用必须始终有效（不能指向已销毁的值，避免悬垂引用）

2. 不可变引用（&T）

  • 核心：只读访问值，不允许修改，支持多个引用共存
  • 示例：
fn print_string(s: &String) {
    println!("{}", s); // 只读访问，不获取所有权
}

fn main() {
    let s = String::from("hello");
    let r1 = &s; // 不可变引用1
    let r2 = &s; // 不可变引用2（允许共存）
    
    print_string(r1); // 传引用，s 仍拥有所有权
    print_string(r2);
    
    println!("s: {}", s); // 正确：s 未失去所有权
}

3. 可变引用（&mut T）

  • 核心：可读写访问值，同一时间只能有一个可变引用（且不能有不可变引用）
  • 示例：
fn modify_string(s: &mut String) {
    s.push_str(", world"); // 可变引用允许修改
}

fn main() {
    let mut s = String::from("hello"); // 变量必须是 mut（可变）才能创建可变引用
    let r1 = &mut s; // 可变引用1
    modify_string(r1);
    println!("r1: {}", r1); // 输出 hello, world
    
    // 错误：同一时间不能有多个可变引用 → error[E0499]: cannot borrow `s` as mutable more than once at a time
    // let r2 = &mut s;
    // println!("r2: {}", r2);
    
    // 引用作用域结束后，可创建新的可变引用
    drop(r1); // 手动结束 r1 的作用域（可选，编译器也会自动回收）
    let r2 = &mut s;
    println!("r2: {}", r2); // 正确
}

4. 悬垂引用（Dangling Reference）

  • 核心：引用指向的 值已被销毁，但引用仍存在 → Rust 编译时禁止这种情况
  • 错误示例（编译不通过）：
fn dangling() -> &String {
    let s = String::from("dangling");
    &s // 错误：s 离开函数作用域会被销毁，返回的引用会悬垂
}
// 编译器错误：error[E0106]: missing lifetime specifier（后续生命周期会讲，核心是禁止悬垂）

关键注意事项

  • 引用必须与所有者生命周期一致：不能返回作用域内临时变量的引用
  • 可变引用的限制：可变引用存在时，不能有任何引用（包括不可变），反之亦然
  • mut 关键字位置：变量本身可变（let mut s）是创建可变引用的前提
  • 引用不影响所有权：函数接收引用时，不会获取所有权，值的生命周期由原所有者决定

六、Rust 数组与切片

数组（Array）是固定长度的栈上集合，切片（Slice）是数组 /Vec 的「动态视图」（不拥有数据），是 Rust 中处理集合的常用工具。

1. 数组（Array）：补充进阶用法

前文已讲基础，这里补充「数组作为函数参数」和「数组与切片的转换」：

// 数组作为函数参数（必须标注长度和类型，如 [i32; 3]）
fn print_array(arr: [i32; 3]) {
    println!("数组：{:?}", arr);
}

fn main() {
    let arr = [10, 20, 30];
    print_array(arr); // 数组是 Copy 类型，传参时浅拷贝（栈上数据）
    
    // 数组转切片（&arr → &[i32]）
    let slice = &arr[1..3]; // 左闭右开区间，取索引1和2 → [20, 30]
    println!("切片：{:?}", slice); // 输出 [20, 30]
}

2. 切片（Slice）：核心特性

（1）核心概念

  • 语法：&[T]（不可变切片）、&mut [T]（可变切片）
  • 本质：包含「数据指针」和「长度」的结构体（struct Slice<'a, T> { ptr: *const T, len: usize }）
  • 特点：
    • 不拥有数据，数据所有权属于原数组 /Vec
    • 动态长度（编译时无需确定）
    • 安全访问（编译器检查索引不越界）

（2）切片的创建与访问

fn main() {
    let arr = [1, 2, 3, 4, 5];
    
    // 方式1：指定范围（&arr[start..end]）
    let slice1 = &arr[1..4]; // 索引1-3 → [2,3,4]
    let slice2 = &arr[2..];  // 从索引2到末尾 → [3,4,5]
    let slice3 = &arr[..3];  // 从开头到索引2 → [1,2,3]
    let slice4 = &arr[..];   // 整个数组 → [1,2,3,4,5]
    
    println!("slice1: {:?}", slice1);
    println!("slice1长度：{}", slice1.len()); // 输出 3
    
    // 方式2：可变切片（原数组必须是 mut）
    let mut arr_mut = [10, 20, 30];
    let slice_mut = &mut arr_mut[1..3];
    slice_mut[0] = 200; // 修改切片 → 原数组也会变
    println!("修改后数组：{:?}", arr_mut); // 输出 [10, 200, 30]
    
    // 安全访问：用 get 方法（返回 Option，避免越界 panic）
    match slice1.get(2) {
        Some(val) => println!("slice1[2] = {}", val), // 输出 4
        None => println!("索引越界"),
    }
}

（3）切片作为函数参数（最常用）

  • 核心优势：函数可接收任意长度的数组 /Vec（无需标注固定长度）
  • 示例：
// 切片作为参数（&[i32] 可接收数组、Vec、其他切片）
fn sum_slice(slice: &[i32]) -> i32 {
    let mut total = 0;
    for &val in slice {
        total += val;
    }
    total
}

fn main() {
    let arr = [1, 2, 3];
    let vec = vec![4, 5, 6]; // Vec（后续集合会讲）
    let slice = &[7, 8, 9];
    
    println!("数组求和：{}", sum_slice(&arr)); // 输出 6
    println!("Vec求和：{}", sum_slice(&vec)); // 输出 15
    println!("切片求和：{}", sum_slice(slice)); // 输出 24
}

关键注意事项

  • 切片不拥有数据：原数组 /Vec 被销毁后，切片也会失效（Rust 编译时检查生命周期）
  • 可变切片修改原数据：切片是视图，修改切片会直接修改原数据
  • 避免切片越界：用 get(index) 代替 slice[index]（越界时返回 None 而非 panic）
  • 数组 vs 切片：数组是固定长度栈上集合，切片是动态长度视图（推荐函数参数用切片）

七、Rust 字符串

Rust 有两种字符串类型：&str（字符串切片）和 String（动态字符串），核心区别是「是否拥有数据」和「是否可变」。

1. 核心概念对比

类型所有权可变性存储位置核心用途
&str无不可变栈 / 堆字符串字面量、函数参数
String有可变堆动态创建、修改字符串

2. &str：字符串切片

  • 语法：用双引号包裹的字面量（如 "hello"），本质是 &[u8]（UTF-8 编码的字节切片）
  • 示例：
fn main() {
    let s: &str = "hello, 世界"; // 字符串字面量 → 编译时存入二进制文件，运行时在只读内存
    
    println!("长度：{}", s.len()); // 输出 11（字节数：hello, 占7字节，世界占4字节）
    println!("字符数：{}", s.chars().count()); // 输出 8（实际字符数）
    
    // 截取切片（按字节索引，注意UTF-8编码，避免截断字符）
    let slice1 = &s[0..5]; // "hello"（安全，未截断字符）
    println!("slice1: {}", slice1);
    
    // 错误：截断中文字符（"世" 占3字节，索引7-9是"世"）
    // let slice2 = &s[7..8]; // 编译通过，但运行时 panic（invalid utf-8 sequence）
}

3. String：动态字符串

  • 核心：在堆上分配内存，支持动态增删改，通过 String::from("xxx") 或 "xxx".to_string() 创建
  • 常用操作示例：
fn main() {
    // 创建 String
    let mut s = String::from("hello"); // 可变 String
    let s2 = "world".to_string();
    
    // 拼接字符串（3种方式）
    s.push('!'); // 追加单个字符 → "hello!"
    s.push_str(", rust"); // 追加 &str → "hello!, rust"
    let s3 = s + &s2; // 拼接两个 String（s 所有权转移给 s3，s 失效）
    println!("s3: {}", s3); // 输出 "hello!, rustworld"
    
    // 格式化拼接（推荐，支持多个变量）
    let name = "Alice";
    let age = 25;
    let info = format!("姓名：{}, 年龄：{}", name, age);
    println!("info: {}", info); // 输出 "姓名：Alice, 年龄：25"
    
    // 截取子串（安全方式：用 chars() 迭代）
    let s4 = String::from(" Rust 编程 ");
    let trimmed = s4.trim(); // 去除首尾空格 → "Rust 编程"
    let first_char = s4.chars().nth(1).unwrap(); // 获取第2个字符（R）
    println!("trimmed: {}, first_char: {}", trimmed, first_char);
    
    // 替换字符
    let replaced = s4.replace("Rust", "RUST");
    println!("replaced: {}", replaced); // 输出 " RUST 编程 "
}

4. &str 与 String 的转换

fn main() {
    // String → &str（自动解引用，无需手动转换）
    let s: String = "hello".to_string();
    let s_slice: &str = &s; // 直接取引用
    
    // &str → String（3种方式）
    let slice = "world";
    let s1 = slice.to_string();
    let s2 = String::from(slice);
    let s3 = format!("{}", slice);
    
    println!("s_slice: {}, s1: {}", s_slice, s1);
}

关键注意事项

  • UTF-8 编码：Rust 字符串默认是 UTF-8，不支持直接按索引访问字符（如 s[0] 是字节，不是字符），需用 chars() 迭代
  • 字符串拼接的所有权：s + &s2 中，s 所有权会转移，s2 需传引用（避免所有权转移）
  • 空字符串：String::new()（空 String）、""（空 &str）
  • 避免字符串截断：截取切片时，必须确保索引落在 UTF-8 字符边界上（否则 panic），推荐用 chars().nth(index)

八、Rust 结构体（Struct）

结构体是 Rust 中自定义复合类型的核心，用于封装多个相关字段，支持方法定义、关联函数等面向对象特性。

1. 结构体的 3 种类型

（1）普通结构体（最常用）

  • 核心：包含命名字段，字段可是任意类型
  • 示例：
// 定义普通结构体（首字母大写，符合 Rust 规范）
struct Person {
    name: String,    // 字符串（拥有所有权）
    age: u32,        // 无符号整数
    is_student: bool,// 布尔值
}

fn main() {
    // 创建结构体实例（字段顺序可任意，需指定字段名）
    let alice = Person {
        name: "Alice".to_string(),
        age: 25,
        is_student: false,
    };
    
    // 访问字段（.字段名）
    println!("姓名：{}", alice.name);
    println!("年龄：{}", alice.age);
    
    // 修改字段（结构体实例必须是 mut）
    let mut bob = Person {
        name: "Bob".to_string(),
        age: 22,
        is_student: true,
    };
    bob.age = 23; // 修改年龄
    println!("Bob修改后年龄：{}", bob.age);
    
    // 结构体更新语法（复用已有实例的字段）
    let charlie = Person {
        name: "Charlie".to_string(),
        ..bob // 复用 bob 的 age 和 is_student 字段
    };
    println!("Charlie年龄：{}", charlie.age); // 输出 23
}

（2）元组结构体（Tuple Struct）

  • 核心：无字段名，仅字段类型，适合简单复合类型（如坐标、颜色）
  • 示例：
// 定义元组结构体
struct Point(i32, i32); // 坐标（x, y）
struct Color(u8, u8, u8); // RGB颜色（r, g, b）

fn main() {
    let p = Point(10, 20);
    let red = Color(255, 0, 0);
    
    // 访问字段（点号+索引）
    println!("x: {}, y: {}", p.0, p.1);
    println!("红色：({}, {}, {})", red.0, red.1, red.2);
    
    // 解构赋值
    let Point(x, y) = p;
    println!("解构后 x: {}, y: {}", x, y);
}

（3）单元结构体（Unit Struct）

  • 核心：无字段，类似空元组 ()，用于标记类型（如实现特质时）
  • 示例：
// 定义单元结构体
struct EmptyStruct;

fn main() {
    let es = EmptyStruct;
    println!("单元结构体：{:?}", es); // 输出 EmptyStruct（需手动实现 Debug 特质）
}

// 为单元结构体实现 Debug 特质（才能用 {:?} 打印）
#[derive(Debug)]
struct EmptyStructDebug;

fn main() {
    let esd = EmptyStructDebug;
    println!("单元结构体（Debug）：{:?}", esd); // 输出 EmptyStructDebug
}

2. 结构体方法（Method）

  • 核心：在 impl 块中定义，第一个参数必须是 &self（不可变引用）、&mut self（可变引用）或 self（所有权转移）
  • 示例：
#[derive(Debug)]
struct Rectangle {
    width: u32,
    height: u32,
}

// 为 Rectangle 实现方法（impl 块）
impl Rectangle {
    // 不可变方法（只读访问 self）
    fn area(&self) -> u32 {
        self.width * self.height
    }
    
    // 可变方法（修改 self，需 &mut self）
    fn scale(&mut self, factor: f32) {
        self.width = (self.width as f32 * factor) as u32;
        self.height = (self.height as f32 * factor) as u32;
    }
    
    // 关联函数（无 self，类似静态方法，用 :: 调用）
    fn square(size: u32) -> Self { // Self 是 Rectangle 的别名
        Self {
            width: size,
            height: size,
        }
    }
}

fn main() {
    let rect = Rectangle { width: 10, height: 20 };
    println!("面积：{}", rect.area()); // 调用方法：rect.area()
    
    let mut rect2 = Rectangle { width: 5, height: 5 };
    rect2.scale(2.0);
    println!("缩放后：{:?}", rect2); // 输出 Rectangle { width: 10, height: 10 }
    
    // 调用关联函数（创建正方形）
    let square = Rectangle::square(8);
    println!("正方形：{:?}", square); // 输出 Rectangle { width: 8, height: 8 }
}

关键注意事项

  • 结构体字段所有权：字段可拥有所有权（如 String）或引用（如 &str，需生命周期标注）
  • impl 块：一个结构体可有多个 impl 块，拆分代码更清晰
  • 方法参数 self：
    • &self：只读，不转移所有权（最常用）
    • &mut self：可修改，不转移所有权
    • self：转移所有权（仅当方法需要消费结构体时使用）
  • 派生特质：用 #[derive(Debug, Clone, Copy)] 可自动实现常见特质（如 Debug 用于打印，Clone 用于复制）

九、Rust 模式匹配（Pattern Matching）

模式匹配是 Rust 中强大的控制流工具，通过 match、if let、while let 等语法，可简洁、安全地处理多种情况（如枚举、结构体、Option 等）。

1. 核心概念

  • 模式：描述数据的结构（如 Some(x)、Person { name, .. }）
  • 匹配：将数据与模式对比，匹配成功则执行对应分支
  • 关键特性：穷尽性检查（编译器确保覆盖所有可能情况）、解构赋值（提取数据）

2. match 表达式（最强大）

（1）匹配枚举（后续枚举会讲，这里用 Option 示例）

Option<T> 是 Rust 用于表示「可能有值或无值」的枚举，定义为：

enum Option<T> {
    Some(T), // 有值
    None,    // 无值
}
  • 示例：
fn get_value(num: Option<i32>) -> i32 {
    // match 穷尽匹配 Option 的所有情况（Some 和 None）
    match num {
        Some(x) => x * 2, // 匹配 Some，提取 x
        None => 0,        // 匹配 None，返回默认值
    }
}

fn main() {
    let a = Some(5);
    let b: Option<i32> = None;
    
    println!("a 的两倍：{}", get_value(a)); // 输出 10
    println!("b 的默认值：{}", get_value(b)); // 输出 0
}

（2）匹配结构体（解构字段）

#[derive(Debug)]
struct Point {
    x: i32,
    y: i32,
}

fn match_point(p: Point) {
    match p {
        // 匹配 x=0，忽略 y（用 _ 通配符）
        Point { x: 0, y: _ } => println!("在 y 轴上"),
        // 匹配 y=0，提取 x（用 @ 绑定变量）
        Point { x, y: 0 } => println!("在 x 轴上，x={}", x),
        // 匹配 x=y，绑定为 val
        Point { x: val, y: val } => println!("x=y={}", val),
        // 匹配所有其他情况（用 .. 忽略剩余字段）
        Point { .. } => println!("其他坐标：{:?}", p),
    }
}

fn main() {
    match_point(Point { x: 0, y: 5 }); // 输出 在 y 轴上
    match_point(Point { x: 3, y: 0 }); // 输出 在 x 轴上，x=3
    match_point(Point { x: 4, y: 4 }); // 输出 x=y=4
    match_point(Point { x: 2, y: 3 }); // 输出 其他坐标：Point { x: 2, y: 3 }
}

（3）匹配数值与通配符

fn match_num(num: i32) {
    match num {
        1 => println!("一"),
        2 | 3 => println!("二或三"), // 多模式匹配（用 | 分隔）
        4..=9 => println!("四到九"), // 范围匹配（..= 包含终点）
        _ => println!("其他数字"),   // 通配符（匹配所有未覆盖的情况，避免穷尽性错误）
    }
}

fn main() {
    match_num(1); // 一
    match_num(3); // 二或三
    match_num(7); // 四到九
    match_num(10); // 其他数字
}

3. if let：简化单分支匹配

  • 核心用途：当只关心一种匹配情况，其他情况忽略时，替代 match（更简洁）
  • 示例：
fn main() {
    let opt = Some(3);
    
    // 等价于 match opt { Some(x) => println!("x={}", x), _ => {} }
    if let Some(x) = opt {
        println!("x={}", x); // 输出 x=3
    }
    
    let point = Point { x: 0, y: 5 };
    // 匹配结构体的单个情况
    if let Point { x: 0, .. } = point {
        println!("在 y 轴上"); // 输出 在 y 轴上
    }
}

4. while let：循环匹配

  • 核心用途：当循环中只关心一种匹配情况时，持续执行直到不匹配
  • 示例：
fn main() {
    let mut stack = vec![1, 2, 3];
    
    // 持续弹出栈顶元素，直到栈为空（None）
    while let Some(val) = stack.pop() {
        println!("弹出：{}", val); // 输出 3、2、1
    }
}

关键注意事项

  • 穷尽性检查：match 必须覆盖所有可能情况，否则编译错误（如 Option 必须匹配 Some 和 None）
  • 通配符 _：用于忽略不需要的字段或值，避免穷尽性错误
  • 绑定变量：用 @ 可将匹配的部分绑定为变量（如 x @ 1..=10）
  • 多模式匹配：用 | 分隔多个模式（如 2 | 3 匹配 2 或 3）

十、Rust 常见集合

Rust 标准库提供了多种常用集合（存储在堆上，动态长度），核心包括 Vec<T>（动态数组）、HashMap<K, V>（键值对）、HashSet<T>（无序集合）等。

1. Vec<T>：动态数组（最常用）

  • 核心特性：动态长度、随机访问、尾部增删高效
  • 语法：Vec::new() 创建空 Vec，vec![] 宏快速创建
  • 常用操作示例：
fn main() {
    // 创建 Vec（3种方式）
    let mut v1: Vec<i32> = Vec::new();
    let mut v2 = vec![1, 2, 3]; // 宏创建，自动推导类型
    let v3 = vec![0; 5]; // 创建 5 个 0 的 Vec → [0,0,0,0,0]
    
    // 尾部添加元素
    v1.push(4);
    v1.push(5);
    println!("v1: {:?}", v1); // 输出 [4,5]
    
    // 访问元素（2种方式）
    println!("v2[0]: {}", v2[0]); // 索引访问（越界 panic）
    match v2.get(1) { // get 方法（越界返回 None，安全）
        Some(val) => println!("v2[1]: {}", val), // 输出 2
        None => println!("索引越界"),
    }
    
    // 遍历 Vec
    for val in &v2 {
        println!("{}", val); // 输出 1、2、3
    }
    
    // 可变遍历（修改元素）
    for val in &mut v2 {
        *val *= 2; // 每个元素乘 2
    }
    println!("v2 乘 2 后：{:?}", v2); // 输出 [2,4,6]
    
    // 插入、删除元素
    v2.insert(1, 3); // 在索引1插入 3 → [2,3,4,6]
    v2.remove(3); // 删除索引3的元素 → [2,3,4]
    println!("v2 插入删除后：{:?}", v2);
    
    // 转换为切片
    let slice = &v2[1..3];
    println!("切片：{:?}", slice); // 输出 [3,4]
}

2. HashMap<K, V>：键值对集合

  • 核心特性：无序、键唯一、基于哈希表实现，需从 std::collections 导入
  • 常用操作示例：
// 必须导入 HashMap
use std::collections::HashMap;

fn main() {
    // 创建 HashMap（2种方式）
    let mut map1: HashMap<&str, i32> = HashMap::new();
    let mut map2 = HashMap::from([("a", 1), ("b", 2)]); // Rust 1.56+ 支持
    
    // 插入键值对（若键已存在，会覆盖值）
    map1.insert("Alice", 25);
    map1.insert("Bob", 22);
    map1.insert("Alice", 26); // 覆盖 Alice 的年龄为 26
    
    // 访问值（2种方式）
    println!("Alice 的年龄：{}", map1["Alice"]); // 索引访问（键不存在 panic）
    match map1.get("Bob") { // get 方法（键不存在返回 None）
        Some(age) => println!("Bob 的年龄：{}", age), // 输出 22
        None => println!("Bob 不存在"),
    }
    
    // 遍历 HashMap（无序）
    for (key, value) in &map1 {
        println!("{}: {}", key, value); // 输出 Alice:26、Bob:22（顺序不确定）
    }
    
    // 插入时检查键是否存在（避免覆盖）
    map1.entry("Charlie").or_insert(23); // 若 Charlie 不存在，插入 23
    map1.entry("Alice").or_insert(30); // 若 Alice 存在，不修改
    println!("map1 插入后：{:?}", map1);
    
    // 更新值（基于旧值）
    let age = map1.entry("Bob").or_insert(0);
    *age += 1; // Bob 的年龄加 1 → 23
    println!("Bob 更新后年龄：{}", map1["Bob"]);
}

3. HashSet<T>：无序集合（无重复元素）

  • 核心特性：无序、元素唯一、基于哈希表，需从 std::collections 导入
  • 示例：
use std::collections::HashSet;

fn main() {
    let mut set = HashSet::from([1, 2, 3, 3]); // 自动去重 → {1,2,3}
    
    // 插入元素（重复元素会被忽略）
    set.insert(4);
    set.insert(2); // 重复，无效果
    
    // 检查元素是否存在
    println!("是否包含 3：{}", set.contains(&3)); // 输出 true
    
    // 遍历集合（无序）
    for val in &set {
        println!("{}", val); // 输出 1、2、3、4（顺序不确定）
    }
    
    // 集合操作（交集、并集、差集）
    let set2 = HashSet::from([3, 4, 5]);
    let intersection: HashSet<_> = set.intersection(&set2).collect(); // 交集 {3,4}
    let union: HashSet<_> = set.union(&set2).collect(); // 并集 {1,2,3,4,5}
    let difference: HashSet<_> = set.difference(&set2).collect(); // 差集 {1,2}
    
    println!("交集：{:?}", intersection);
    println!("并集：{:?}", union);
    println!("差集：{:?}", difference);
}

关键注意事项

  • 集合的可变性：所有集合的修改操作（push、insert、remove）都需要 mut 关键字
  • HashMap 的键要求：键必须实现 Eq 和 Hash 特质（标量类型、String 等默认实现）
  • 遍历顺序：HashMap 和 HashSet 是无序的，若需要有序，用 BTreeMap/BTreeSet
  • 内存管理：集合存储在堆上，元素被自动销毁（所有权由集合拥有）

十一、Rust 返回值与错误处理

Rust 的错误处理哲学是「显式错误」，避免隐式异常（如 Java 的 Exception），核心通过 Result<T, E> 处理可恢复错误，panic! 处理不可恢复错误。

1. 不可恢复错误：panic!

  • 核心用途：处理逻辑错误（如数组越界、断言失败），触发后程序终止并打印调用栈
  • 示例：
fn main() {
    // 手动触发 panic
    // panic!("程序异常终止");
    
    let arr = [1, 2, 3];
    // 数组越界 → 自动 panic（调试模式下打印详细调用栈）
    // println!("{}", arr[5]);
}
  • 注意：发布模式（cargo build --release）下，panic! 会优化调用栈打印，仅输出错误信息

2. 可恢复错误：Result<T, E>

Result<T, E> 是 Rust 用于表示「成功返回 T 类型」或「失败返回 E 类型」的枚举，定义为：

enum Result<T, E> {
    Ok(T),  // 成功
    Err(E), // 失败
}

（1）返回 Result 并匹配处理

use std::fs::File;

// 读取文件：成功返回 File，失败返回 io::Error
fn read_file(path: &str) -> Result<File, std::io::Error> {
    File::open(path) // File::open 本身返回 Result<File, io::Error>
}

fn main() {
    match read_file("test.txt") {
        Ok(file) => println!("文件打开成功：{:?}", file),
        Err(e) => println!("文件打开失败：{}", e), // 输出错误信息（如 "No such file or directory"）
    }
}

（2）? 操作符：简化错误传播

  • 核心用途：当函数返回 Result 时，用 ? 自动处理 Err（直接返回错误），仅保留 Ok 的值
  • 示例：
use std::fs::File;
use std::io::{self, Read};

// 读取文件内容：错误自动传播（无需手动 match）
fn read_file_content(path: &str) -> Result<String, io::Error> {
    let mut file = File::open(path)?; // ? 自动处理 Err：返回错误
    let mut content = String::new();
    file.read_to_string(&mut content)?; // ? 再次传播错误
    Ok(content) // 成功返回 Ok(content)
}

fn main() {
    match read_file_content("test.txt") {
        Ok(content) => println!("文件内容：{}", content),
        Err(e) => println!("读取失败：{}", e),
    }
}

（3）自定义错误类型

  • 核心：通过枚举定义自定义错误类型，实现 std::error::Error 特质（用于统一错误处理）
  • 示例：
use std::error::Error;
use std::fmt;

// 自定义错误类型
#[derive(Debug)]
enum MyError {
    FileError(std::io::Error),    // 包装 IO 错误
    ParseError(String),           // 解析错误
}

// 实现 fmt::Display（错误信息格式化）
impl fmt::Display for MyError {
    fn fmt(&self, f: &mut fmt::Formatter) -> fmt::Result {
        match self {
            MyError::FileError(e) => write!(f, "文件错误：{}", e),
            MyError::ParseError(s) => write!(f, "解析错误：{}", s),
        }
    }
}

// 实现 Error 特质（标记为错误类型）
impl Error for MyError {}

// 包装 IO 错误（从 io::Error 转换为 MyError）
impl From<std::io::Error> for MyError {
    fn from(e: std::io::Error) -> Self {
        MyError::FileError(e)
    }
}

// 读取并解析文件（返回自定义错误）
fn parse_file(path: &str) -> Result<i32, MyError> {
    let content = read_file_content(path)?; // ? 自动将 io::Error 转换为 MyError（因 From 实现）
    content.parse().map_err(|_| MyError::ParseError("无法转换为整数".to_string()))
}

fn main() {
    match parse_file("number.txt") {
        Ok(num) => println!("解析结果：{}", num),
        Err(e) => println!("错误：{}", e),
    }
}

关键注意事项

  • ? 的使用限制：只能在返回 Result 或 Option 的函数中使用
  • 错误转换：用 From 特质可自动将一种错误转换为另一种（如 io::Error → 自定义错误）
  • 错误链：用 source() 方法可获取原始错误（需实现 Error 特质）
  • 优先用 Result 而非 panic!：除逻辑错误外，尽量返回 Result 让调用者处理错误（更灵活）

十二、Rust 模块化

Rust 的模块化系统用于组织代码（拆分文件、控制访问权限），核心是 mod（定义模块）、pub（暴露公共接口）、use（导入模块 / 成员）。

1. 核心概念

  • 模块（Module）：代码的逻辑分组（如 user 模块、utils 模块）
  • 包（Crate）：Rust 的编译单元（可执行程序或库）
  • 路径（Path）：访问模块成员的方式（如 crate::user::User、std::fs::File）
  • 访问控制：默认私有（模块内可见），用 pub 标记为公共（外部可访问）

2. 单文件模块

（1）定义模块与访问控制

// 定义模块（默认私有）
mod utils {
    // 私有函数（仅 utils 模块内可见）
    fn private_func() {
        println!("utils::private_func");
    }
    
    // 公共函数（外部可访问）
    pub fn public_func() {
        println!("utils::public_func");
        private_func(); // 模块内可访问私有函数
    }
    
    // 嵌套模块
    pub mod math {
        pub fn add(a: i32, b: i32) -> i32 {
            a + b
        }
    }
}

// 定义公共模块（直接暴露给外部）
pub mod user {
    // 公共结构体
    pub struct User {
        pub name: String, // 公共字段
        age: u32,         // 私有字段（仅 user 模块内可见）
    }
    
    impl User {
        // 公共构造函数
        pub fn new(name: &str, age: u32) -> Self {
            Self {
                name: name.to_string(),
                age,
            }
        }
        
        // 公共方法（访问私有字段）
        pub fn get_age(&self) -> u32 {
            self.age
        }
    }
}

fn main() {
    // 访问模块成员：路径方式
    utils::public_func(); // 输出 utils::public_func → utils::private_func
    let sum = utils::math::add(3, 5);
    println!("sum: {}", sum); // 输出 8
    
    // 访问公共结构体
    let u = user::User::new("Alice", 25);
    println!("姓名：{}", u.name); // 访问公共字段
    println!("年龄：{}", u.get_age()); // 通过方法访问私有字段
    
    // 错误：无法访问私有成员
    // utils::private_func();
    // println!("{}", u.age);
}

（2）use 关键字：简化路径

// 导入模块成员，简化访问
use utils::math::add;
use user::User;

fn main() {
    // 无需写完整路径
    let sum = add(3, 5);
    println!("sum: {}", sum);
    
    let u = User::new("Bob", 22);
    println!("姓名：{}", u.name);
    
    // 导入整个模块
    use utils::math;
    println!("math::add(2,3) = {}", math::add(2,3));
    
    // 别名导入（避免冲突）
    use utils::public_func as pub_func;
    pub_func();
}

3. 多文件模块（实际项目常用）

当模块代码较多时，可拆分为独立文件，目录结构如下：

src/
├── main.rs          # 入口文件
├── utils/           # utils 模块目录
│   ├── mod.rs       # utils 模块入口（必须）
│   └── math.rs      # utils::math 模块
└── user.rs          # user 模块

（1）src/user.rs（user 模块）

// 公共结构体
pub struct User {
    pub name: String,
    age: u32,
}

impl User {
    pub fn new(name: &str, age: u32) -> Self {
        Self {
            name: name.to_string(),
            age,
        }
    }
    
    pub fn get_age(&self) -> u32 {
        self.age
    }
}

（2）src/utils/math.rs（utils::math 模块）

pub fn add(a: i32, b: i32) -> i32 {
    a + b
}

pub fn multiply(a: i32, b: i32) -> i32 {
    a * b
}

（3）src/utils/mod.rs（utils 模块入口）

// 私有函数
fn private_func() {
    println!("utils::private_func");
}

// 公共函数
pub fn public_func() {
    println!("utils::public_func");
    private_func();
}

// 导入 math 模块（公共暴露）
pub mod math; // 对应 math.rs 文件

（4）src/main.rs（入口文件）

// 导入多文件模块
mod utils; // 对应 utils/mod.rs
mod user;  // 对应 user.rs

// 简化访问
use utils::math::{add, multiply};
use user::User;

fn main() {
    utils::public_func();
    
    println!("add(3,5) = {}", add(3,5));
    println!("multiply(2,4) = {}", multiply(2,4));
    
    let u = User::new("Charlie", 30);
    println!("{}: {}", u.name, u.get_age());
}

关键注意事项

  • 模块命名规范：模块名用小写蛇形命名（如 utils_math）
  • pub 的作用范围：pub 仅暴露给父模块，子模块的公共成员需显式标记
  • mod.rs 的作用：目录模块必须有 mod.rs（Rust 2018+ 也支持直接用目录名.rs，但 mod.rs 更通用）
  • 绝对路径 vs 相对路径：
    • 绝对路径：从 crate 根开始（如 crate::utils::math::add）
    • 相对路径：从当前模块开始（如 super::parent_func，super 表示父模块）
