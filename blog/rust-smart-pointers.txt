13:T1ae83,<h2>Box</h2>
<p>最简单的智能指针，rust的大部分标准库struct或标量类型是优先采用stack分配内存的。在大部分语言中，stack大小是在编译期确定的，二heap大小是在运行期确定的。rust中可以使用Box把任意类型放到heap中存储。
使用场景：</p>
<ul>
<li>某个类型编译时大小未知，但是需要在确定大小的上下文中使用这个类型。</li>
<li>当有大量数据，并且希望数据不被拷贝的情况下仅仅只是转移所有权。</li>
<li>当希望拥有一个值，并且只关心它时候实现了某个trait而不关心值的具体类型的时候。</li>
</ul>
<h2>Rc</h2>
<ul>
<li>在编译时确定借用数量，如果不符合借用规则，则报错。</li>
<li>xxxxxxxxxx     let str = br#####"rock"####"jiang"#####;    println!("{:?}", str);rust</li>
<li>xxxxxxxxxx fn main() {    let mut i = 42;    let x = &#x26;i;    let y: &#x26;mut i32 = x;}rust</li>
<li>strong_count()函数返回强引用计数，数量。</li>
<li>weak_count()函数返回弱引用计数，数量。</li>
<li>当强引用计数清零后才可以Drop。</li>
</ul>

<h2>RefCell</h2>
<ul>
<li>在运行时确定借用数量，如果不符合借用规则，则报错。</li>

<h2>Mutex</h2>
<ul>
<li>能够保证同一时刻只有一个线程可以访问锁。</li>
<li>访问数据前，需要先获得锁。</li>
<li>处理完Mutex保护的数据后，必须立刻解锁，保证其他线程可以在第一时间获得锁。</li>
<li>不像是java中有unlock来释放锁。在rust中可以通过drop释放Mutex的保护数据，来在作用域中释放Mutex。</li>
</ul>

<h2>RwLock</h2>
<ul>
<li>成为read-write锁，以下read简称r，write简称w。</li>
<li>站在Java的角度与ReentrantReadWriteLock类似，读贡献，写互斥。</li>
<li>大家从如下的打印数据也可以看出来，r可以共享数据，但是w互斥。但是r与w彼此之间也是互斥的。</li>
